# Source scope

This repository contains the canonical registry at revision 138, the graph gate, discovery and publication code, map renderer, task context builder, prompts, and 44 registered evidence/source artifacts. It excludes raw conversation transcripts, unregistered scratch proposals, local hosting credentials, historical generated sites, deployment bundles, and original Git history.

Generate the map from source with `python scripts/build_pages.py`. The evidence artifacts retain their exact bytes so their recorded SHA-256 hashes remain meaningful. Historical research-state labels and selected routes are retained; packaging the project does not imply additional research approval. Source attribution and uncertainty remain attached to the underlying research.

Provenance references prefixed with `source-project/` or `local-source/` identify material in the original working projects; they are historical provenance labels rather than paths readers need to recreate. Graph IDs, selected relationships and evidence artifact bytes were retained. The registry remains revision 138.

Some node metadata references historical drafts that were not registered evidence and are not bundled here. Generated pages label those omissions as historical references instead of linking to missing files. Registered evidence remains byte-preserved and hash-checked.
